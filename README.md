## Solution Format

Each solution contains:

- Problem name
- LeetCode problem number
- Difficulty
- Problem-solving approach
- Explanation
- Time complexity
- Space complexity
- Java implementation


## Goal

Solve problems consistently, understand the underlying patterns,
and improve the ability to recognize which approach to use for a
new problem.

---
i don't want comments that simply describe what a line of Java does. i want the complete problem-solving logic written inside the code itself, so that even after several months, when i open my Java file, read the comments from top to bottom, understand the entire problem, and independently write the solution without looking at the implementation.

code notes self-contained:
- Explain the problem in simple words.
- Use a real-life story or analogy.
- Explain how we arrive at Binary Search instead of a normal loop.
- Explain why every variable exists.
- Explain the logic behind every condition.
- Explain why low and high move in particular directions.
- Include a complete dry run inside the comments.
- Explain the time and space complexity.
- Preserve your original code and variable names.
